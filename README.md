# Vet Manager
Manages scheduling for a veterinary hospital. Adds and removes patient records and appointments as needed by the veterinary receptionist(s). Features queues, linked lists, and enumerator Java/Object Oriented Programming concepts. Also demonstrates interfaces, exception handling, and appointment management operations.
